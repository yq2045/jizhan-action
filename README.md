# 激战行动 · Operation Aftermath

手机与电脑均可玩的 2D 直升机战斗游戏。使用原生 Canvas 和 JavaScript，无需构建或安装依赖。黑黄直升机由代码原创绘制，参考用户提供的外形与收轮状态；仓库不包含参考截图。

## 本地运行

```sh
python3 -m http.server 4173 --directory dist
```

打开 http://localhost:4173 。也可以直接打开 dist/index.html。

## 操作

- WASD / 方向键：滑跑、水平移动、升降。滑跑速度达到 85 后按 W 助推起飞，耗能 30。
- 鼠标瞄准，按住左键或空格：机枪，0.1 秒冷却，每发 1 能量。
- F：切换自动射击，仅当黄色虚线扫过敌人时触发。
- Q，然后点击战场位置：导弹，25 能量，10 秒冷却。
- G：渐变收放起落架，收起耗能 30，放下免费。
- R：使用修补道具，恢复 50 耐久。
- E：使用雷达，持续 60 秒，红点敌军，绿点我方。
- Esc：暂停。
- 手机：左侧摇杆移动，点击战场瞄准，右侧开火，底部功能按钮。推荐横屏。

机体耐久与能量均为 100，能量每秒恢复 1。着陆前放下起落架，下降速度低于 65，保持平稳；重着陆会扣血，高速撞地或收轮着陆将坠机。地图长度 10,000，18 辆坦克，每辆奖励 150 资金。

## 升级与保存

主菜单商店可升级机枪和导弹，最高三级。三级导弹带粗橙条纹、橙色拖尾和有限追踪；升级增加伤害和尾焰。修补和雷达为消耗品。初始资金 600，各附赠一件道具。进度保存在 localStorage，清除浏览器数据会重置；不同设备独立存档。

## 验证

```sh
node --check dist/game.js
node test-game.cjs
```

包含 10 项核心逻辑检查，并已在浏览器检查菜单、实战、起飞、自动射击和雷达，以及窄屏和电脑布局。碰撞使用旋转机身采样点与建筑、地面碰撞，子弹使用线段碰撞。当前为单人原型，未接入完整刚体变形引擎。
